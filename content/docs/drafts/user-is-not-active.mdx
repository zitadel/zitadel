# User is Not Active

## Description

This message indicates that the user account is currently inactive. This could be due to various reasons such as the account being deactivated by an administrator, a suspension due to policy violations, or the account not being verified.

## Resolution Steps

1. **Verify Account Status**: Check if the account has been deactivated or suspended by an administrator. Contact your system administrator for more information.

2. **Account Verification**: Ensure that the account has been properly verified. If not, follow the verification process as outlined in the user registration documentation.

3. **Policy Compliance**: Review any recent communications from the system regarding policy violations. Ensure compliance with all user policies to avoid suspension.

4. **Contact Support**: If the above steps do not resolve the issue, contact technical support for further assistance.

## Additional Information

For more detailed information on user account statuses and management, refer to the [User Account Management Guide](../user-account-management-guide).
